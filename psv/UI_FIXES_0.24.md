# 0.24 PSV 文字颜色与聚焦白框

日期：2026-09-30。

通用动态文字此前使用 `RGB(238,242,247)`，而对白字形为 `RGB(255,255,255)`，形成了色差。现在人名、选项、存档时间和摘要、设置字体名称、历史页码及提示统一用纯白。浅色底图中的姓名输入、普通系统确认文字继续使用显式深色，避免白底白字。

移除按钮、滑条和姓名输入框的额外焦点矩形。方向键导航保留：有原始热态图的按钮仍切换图片，其余控件旁绘制小箭头；鼠标/触摸后取消导航提示。姓名编辑显示末尾的深色文字光标。控件原本的图集边饰、选中状态和禁用状态保留。

本轮复用现有 72 个输入事件及 26 屏 UI 检查，全部通过；进行内存画布比较，不输出截图。VitaSDK 构建和版本 00.24 安装包校验后交付。0.23 的 AVC 连续主内存修复保留，电影数据和播放实现未更改，实机播放仍待验证。
