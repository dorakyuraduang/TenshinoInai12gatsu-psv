BGM 主轨继续流式读取。换曲只展开旧曲 0.3 秒音频，避免同时展开两整首音乐；对于当前 44.1 kHz 双声道音频约 53 KiB。环回及单次播放结束边界均比较了原始 PCM。

## 本轮验证结果

- 独立 `parity-audit.ps1`：**41/41** 个定向检查符合源码预期；结果见 `tests/parity-results-0.17.json`。旧基准的 20 点包含在内。这些检查不是全游戏通过率，也不是在两个引擎中逐帧对拍。
- 重新编译剧情测试：三组路线 **4,690 / 6,767 / 7,092** 个事件逐项匹配 C# 参考，包含存读档；**8,901** 个对白位置恢复旧版消息元数据一致。
- `message-bytes-reference.py` 使用 .NET 的 GB18030 编码，验证 **15,983** 条未经格式化的文本（含姓名占位符、控制码和四字节字符边界）。
- 音频流测试 **112** 个条目通过；24 首音乐的开始、中间、末尾和结束后位置，在循环/非循环下共 **192** 组重叠片段与完整 PCM 参考一致。
- `--input-smoke`：**72** 个排队事件；包含拖动/滚轮、松手触发、移出取消、重复输入过滤、按下外观及方向键/指针焦点切换。`--ui-smoke`：**26** 个界面、40 槽分页通过。
- 首次序章完成、重复启动 OP、旧版无消息字段存档、旧完成标记迁移和独立进程读档通过。
- 思源黑体覆盖仍为 **31,964** 组布局、**3,274** 个字符，缺字 **0**。
- VitaSDK ARM 编译和 VPK 00.17 打包；发布脚本检查 SELF、图标、内置字体、OFL 和来源资料。

测试都在独立状态目录执行，没有更改用户 Vita3K 数据；没有生成或发送游戏截图。

## 仍需区分的边界

- 内置思源黑体是用户已选择的授权字体，字形及 SDL_ttf 栅格与 Godot 原 SimHei/GDI 不会完全相同。消息阴影参照 Windows 路径，Godot 非 Windows 回退路径本身也有所不同。
- 存档文件格式不与 Godot 互通。新包允许并恢复 PSV 自身的回想快照；Godot 的路线重放后端对部分回想存档仍可能找不到场景，两者不能宣称全部存档条件相同。旧版在非对白等待/选项中保存的快照保留其历史位置，不强制重写用户存档。
- 主机 SDL 测试和 SDK 编译不能代替 Vita3K/PSV 真机验收。触摸硬件、实体按键、系统输入法、真实休眠、帧率、峰值内存、长时稳定性和 OP 音画同步仍待验证。
- Godot 自身未还原的转场 12/41/50、Logo 50/54/55 专用滤镜仍保留既有淡化实现。天气随机序列、固定屏幕和系统字体选择等平台差异继续存在。
- Godot 本身每次启动播放 OP、通过手动存档继续，本轮没有改成退出自动续玩。
